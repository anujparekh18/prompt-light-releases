Prompt Light 1.1.2 fixes task status getting stuck after Codex completes work
that uses subagents.

## Fixed

- The light now returns to green when a completed parent task still has
  subagent turn records.
- Subagent turns are grouped under their parent task instead of being reported
  as separate running tasks.
- Concurrent top-level Codex tasks continue to be tracked independently.

## Requirements

- macOS 14 Sonoma or later.
- Apple silicon or Intel Mac.
- Codex for automatic activity updates.

The app is signed with a Developer ID certificate and notarized by Apple.
