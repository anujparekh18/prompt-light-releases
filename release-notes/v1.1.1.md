Prompt Light is a native macOS menu-bar utility that shows Codex activity with
a hanging traffic signal.

## Highlights

- Red while a Codex task is working, amber when it needs attention, and green
  when it is ready.
- Correct aggregation across concurrent Codex tasks.
- One-click Codex hook installation that preserves unrelated hooks.
- NYC-style traffic-light artwork with weighty drag-and-pull physics.
- Fullscreen and Spaces support with a remembered display position.
- Click-through mode, opacity and size controls, launch at login, optional
  completion sound, Reduce Motion support, and stale-task recovery.
- One-screen onboarding and production-focused menu-bar controls.

## Requirements

- macOS 14 Sonoma or later.
- Apple silicon or Intel Mac.
- Codex for automatic activity updates.

The app is signed with a Developer ID certificate and notarized by Apple.
