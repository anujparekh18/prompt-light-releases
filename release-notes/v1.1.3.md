Prompt Light 1.1.3 adds secure automatic updates.

## Added

- Prompt Light now checks for updates automatically and can install them in place.
- A **Check for Updates…** command is available from the menu bar.
- General Settings shows the installed version and an update action.
- Update archives and the update feed are cryptographically signed.

## Upgrading from 1.1.1 or 1.1.2

Those versions did not include an updater, so 1.1.3 requires one final manual
download. Future releases can update automatically from 1.1.3 and later.

## Requirements

- macOS 14 Sonoma or later.
- Apple silicon or Intel Mac.
- Codex for automatic activity updates.

The app is signed with a Developer ID certificate and notarized by Apple.
